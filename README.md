# SiteLens — Website Audit Portfolio MVP

A dark, polished website audit app built with **Next.js App Router, React, TypeScript, CSS, and the Google PageSpeed Insights API**. Created as a demonstrable portfolio project for Arif Hassan.

## What works

- Enter a public website URL, select **Mobile** or **Desktop**, and request live Google Lighthouse scores.
- View **Performance, Accessibility, Best Practices, SEO** (0–100 when the API reports them).
- View FCP, LCP, CLS, TBT, Speed Index and Lighthouse performance opportunities.
- Export a report via browser **Print / Save as PDF**, or copy a text summary.
- Explore a clearly labeled **illustrative sample report** before running a live audit.
- Responsive dashboard without signup or a database.

**This is not yet an AI tool.** Recommendations are sourced from Google Lighthouse, not generated by a language model. To make it an AI product later, add an opt-in LLM summarizer through a server route with safe prompt handling, disclosure, and usage limits.

## Install and start (Windows / VS Code)

1. Install **Node.js 20.9+** (Node.js 22 LTS is suitable).
2. Extract this ZIP into a folder.
3. Open the folder in VS Code and run in Terminal:

```bash
npm install
```

4. (Recommended) Copy `.env.example` to `.env.local` and put your **Google PageSpeed Insights API key** in it:

```dotenv
PAGESPEED_API_KEY=YOUR_GOOGLE_CLOUD_API_KEY
```

   Enable the PageSpeed Insights API in Google Cloud Console. It may allow some keyless requests but can reject/rate-limit them: **use an API key for reliable testing**. Do not prefix this variable with `NEXT_PUBLIC_`, and do not commit `.env.local`.

5. Start the app:

```bash
npm run dev
```

6. Open `http://localhost:3000` in your browser and try an accessible public domain.

For build checks:

```bash
npm run typecheck
npm run lint
npm run build
```

## Scope and limitations

- No actual redesign generator or AI integration is included yet.
- Lighthouse scores change between runs and do not represent a contractual guarantee.
- Some target websites block Lighthouse scanning; API availability, quotas, and cost are controlled by Google.
- Public Google Lighthouse/PageSpeed service receives the URL entered by the user; do not analyze private URLs.
- No login, payments, storage, or permanent shareable report URL is implemented.
- For public production usage add **rate limiting, abuse prevention, monitoring, logging, and error budget**. Current endpoint has input validation but **no per-user rate limiting**.
- Google's API can time out; some serverless hosts impose shorter execution limits. Configure host functions appropriately.
- The little dashboard inside the hero is **decorative**; the real sample and live audit are displayed below.
- `example.com` in the sample is fictional data; **never claim the scores measured that domain**.
